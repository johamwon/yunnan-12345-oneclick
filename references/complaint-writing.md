# 云南 12345 诉求写作规范

> 目标：把「一句话吐槽」变成受理部门能**直接派单、能核查、能答复**的工单正文。
> 原则：**要素优先于文采，事实优先于评价，诉求优先于情绪。**

---

## 一、八要素：写什么 / 不写什么

| 要素 | 必填 | 要求 | 反面 | 正面 |
|------|:---:|------|------|------|
| 发生时间 | ✅ | 具体到日期；持续性问题写起止与频次 | 「最近」「好久了」 | 「2026年10月22日起，每晚22:00至次日2:00」 |
| 发生地点 | ✅ | 州市 + 区县 + 道路/门牌/小区/场所全称 | 「我家楼下」 | 「昆明市五华区人民中路128号XX小区3栋南侧工地」 |
| 涉及单位 | 建议 | 全称或可识别称呼；不确定写「不详，请核实」 | 「他们」「有关部门」 | 「施工方XX建设公司（围挡公示牌）」 |
| 事项经过 | ✅ | 时间顺序 3–5 句，一句一个动作 | 大段情绪宣泄 | 「22:00 起打桩；23:30 联系物业无人接听；次日1:00 仍在浇筑」 |
| 造成影响 | 建议 | 带数字：时长/次数/金额/面积/人数 | 「影响很大」 | 「连续3晚无法入睡，家人上班上学受影响」 |
| 证据材料 | 建议 | 列举材料类型与数量 | 「有证据」 | 「带时间水印视频2段、通话记录3条」 |
| 前期反映 | 建议 | 时间 + 渠道 + 对方答复 | 「反映了没人管」 | 「10月23日向物业反映，答复『不归我们管』」 |
| 具体诉求 | ✅ | 可执行 + 可核查 + 有时限 | 「尽快处理」 | 「责令停止22:00后施工；3个工作日内书面告知结果」 |

缺「涉及单位」时写「不详，请核实」，比留空好——明确告知部门需自行核实主体。

## 二、版式

**标准版**（推荐）

```
【诉求事项】一句话标题（20字内：地点/对象 + 问题）
【发生时间】…
【发生地点】…
【涉及单位】…
【事项经过】按时间顺序的事实
【造成影响】…
【证据材料】…
【前期反映】…
【具体诉求】
1. …
2. …
```

**压缩版**（正文紧张时用 `--compact` 生成）：时间+地点+对象压进首句，末尾一句写诉求。

云南平台没有独立标题栏，标题写在正文首行的【诉求事项】里即可。

---

## 三、诉求怎么写才有效

有效的诉求 = **动作 + 对象 + 时限 + 可核查结果**

| 弱 | 强 |
|----|----|
| 尽快处理 | 责令施工方停止每日 22:00 后的施工作业 |
| 希望重视 | 安排执法人员 3 个工作日内到现场核查并书面告知结果 |
| 退款 | 责令商家退还多收费用 120 元（2026-10-20 订单号 XXX） |
| 管一管 | 对该路段占道经营开展清理，并说明后续巡查安排 |

规则：
1. 一条一个诉求，编号列出；超过 4 条时按优先级排序。
2. 时限用「工作日」。
3. 不替部门指定处罚措施（不要写「必须罚款5000元」），写「依法查处」；法条不确定就不要写条款号。
4. 需要答复就写「请书面或短信告知处理结果」，便于后续查询与复议。

## 四、改写对照

| 原话 | 问题 | 改后 |
|------|------|------|
| 「物业就是垃圾，收钱不办事」 | 情绪化 + 无事实 | 「物业为XX物业，10月起未按合同清理楼道垃圾，10月20日、23日两次反映未处理」 |
| 「有关部门不作为」 | 定性结论 | 「10月20日反映后，截至10月26日未收到任何答复」 |
| 「肯定是他们偷排」 | 推断当事实 | 「夜间有刺鼻气味，来源疑似厂区东南侧排口，请核查」 |
| 「已经好久了」 | 无时间锚点 | 「自2026年9月中旬起，已持续约40天」 |
| 「不解决我就曝光」 | 威胁性表述 | 「请依法处理并书面答复；如未处理，我将通过法定渠道继续反映」 |

不做的事：不编时间/单位/金额/单号；不把推测写成事实；不加用户没说的法条与政策文件。

## 五、云南专属注意

### 1. 行政区划要选到「叶子」

云南平台是三级级联（州市 → 区县 → 街道/社区），且**只认末级**：

```
昆明市 / 五华区 / 护国街道办事处     ✅ 有效
昆明市 / 五华区                      ❌ 只展开了，没有值
```

- 部分区县下还有街道/乡镇；滇池旅游度假区下有 27 个小区级叶子
- 脚本支持 `--district "昆明市/五华区/护国街道"` 三级直填；只给「五华区」会自动补州市，街道需在浏览器内点选（`--no-headless`）
- 正文里的「发生地点」写**具体路段/门牌**，与表单的「详细地址」互补

### 2. 匿名提交 → 正文里不要堆个人信息

匿名通道姓名栏是禁用的，平台只采集手机号。因此：

- 手机号填在表单字段，**不要写进正文**
- 不写身份证号、银行卡号
- 涉及他人用「3栋某住户」「店内一名男性员工」，不写姓名电话
- 涉及未成年人只写「未成年子女」，不写学校班级

### 3. 字数

正文上限 **2000 字**（含标点）。超过用 `--compact`，仍超就拆成「主诉求 + 补充说明」两条，别硬塞。

### 4. 一事一单

三件不相关的事塞一个工单会被拆单或退回。同一事项的不同侧面（噪音 + 超时施工）可以合并。

## 六、用户只给一句话时的追问顺序

按「影响派单的要素」优先，一次问 3–4 个，每项都给示例答案：

1. **地点**：哪个州市？哪个区县/街道？具体到哪条路/哪个小区？（决定投到哪个辖区）
2. **时间**：哪天开始、几点、持续多久、是否每天发生？
3. **经过**：谁做的、做了什么、现场看到什么、对方怎么回应？
4. **诉求**：希望他们具体做什么？多久内答复？
5. （可选）证据、影响数字、此前反映记录

问完跑 `run`，把 `[缺要素]` 剩余的补齐，再进入确认与提交。
