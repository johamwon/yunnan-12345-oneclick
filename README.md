# 云南 12345 一键诉求 Skill

## 这个 Skill 是做什么的

本 Skill 用于帮助用户整理并提交云南省 12345 政务服务便民热线诉求。它可以根据用户提供的事实和地点信息，协助梳理诉求内容、补充必要表达，并在用户确认后，代替用户完成网页表单中的重复填写操作。

## 它解决什么问题

提交 12345 诉求时，用户通常需要反复处理以下事项：

- 整理零散描述，明确问题发生的时间、地点、对象和具体影响；
- 判断并填写对应的行政区划信息；

本 Skill 旨在减少这些机械、重复的手工操作，让用户更方便地准备和提交自己的真实诉求。正式提交前，用户应自行核对内容并明确确认。
